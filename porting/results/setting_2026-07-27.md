## Implementation being measured

The final benchmark must measure the current optimized architecture, not an
older intermediate build:

- fixed format/mode/value/error discriminants are enums;
- fixed document/result fields are direct members;
- dynamic keys resolve once to object-local dense `SettingKeyId` values;
- hot object access is direct indexed access with no hash/string comparison;
- `SettingInteger` keeps signed/unsigned 64-bit values in compact heap-free
  lanes and promotes only out-of-range values to Boost `cpp_int`;
- JSON builds the AST directly through per-thread reusable SAX state, using an
  imprecise fast conversion route plus a precise float fallback;
- owned keys and `{key_view, value}` entries are separate contiguous vectors;
- parser-owned keys transfer through `set_owned()` and bulk construction uses
  `reserve()` for the key/entry/hash lanes;
- YAML lexicographic order is a compact-ID cache with an atomic clean fast path
  and a mutex-protected rebuild;
- batch work uses the persistent deterministic executor, bounded affinity,
  ordered results, lowest-input-index errors, and sequential reentrant fallback.
