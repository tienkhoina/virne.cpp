# PyG-lite gate — 2026-08-04

Status: **PASS** on Linux CPU and Windows CPU.

Python oracle: Torch 2.6.0 + PyG 2.7.0. The paired timing loaded the same Torch
shared libraries for Python and C++, compiled the native harness with GCC 14
`-O3`, fixed Torch to one thread, and interleaved sample order. Each median used
five repetitions, two warmups, and two iterations per repetition.

| Case | Python | C++ | C++ speedup | Output |
|---|---:|---:|---:|---|
| Utility pipeline | 7.291 ms | 7.018 ms | 1.039x | PASS |
| GCN | 11.995 ms | 6.546 ms | 1.832x | PASS |
| GAT | 22.729 ms | 24.294 ms | 0.936x | PASS |

Differential result: **59/59 bit-exact**, maximum absolute error `0`. The GAT
result is retained without hiding its small regression; immutable-topology
self-loop preparation is the next optimization boundary.

Reproduce from the C++ checkout mounted at `/work`:

```powershell
docker run --rm `
  --mount "type=bind,source=$((Resolve-Path .\virne.cpp).Path),target=/work" `
  -w /work virne-cpu:latest `
  python porting/compare_pyg_lite.py `
    --harness /work/build-pyg-oracle/vne_pyg_lite_harness `
    --mode all --device cpu --threads 1 `
    --warmups 2 --repetitions 5 --iterations 2
```
