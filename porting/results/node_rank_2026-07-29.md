## Stable API

`NodeRanker::prepare()` returns a non-owning `PreparedNodeRanker`. Its typed
method-specific `rank_*` calls return ordered `NodeRanking` entries with fixed
node ID, scalar/proximity kind, value, and distance fields. Selection uses
typed registry IDs; `NodeRankOptions` directly owns sort, workers, and optional
iteration limit; GRC/RW parameters are fixed structs. Random ranking requires
an explicit `NumpyRandomState&`. `NodeRankErrorCode`, `NodeRankOperation`, and
`NodeRankException` expose typed failure and input/resource/node metadata.
